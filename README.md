# 🛒 Online Auction Platform

## 📌 Overview
A full-stack web application for online bidding and auctions, built with Django, Python, SQL, and JavaScript.  
Users can list items, place bids in real-time, and manage auctions securely.

## 🚀 Features
- User registration & authentication
- Create and manage auction listings
- Real-time bidding system
- Admin dashboard for managing users and auctions
- Responsive UI with HTML, CSS, and JavaScript

## 🛠️ Tech Stack
- Django & Django REST Framework
- Python
- HTML, CSS, JavaScript
- MySQL / Oracle SQL
- Git & GitHub
